Typography and fonts

The theme has two independent font systems: Shopify's font pickers, which are the default, and four typefaces bundled with the theme and served from your own store. You can use either, and switching does not require code.

They are not mixed

Turning on bundled fonts replaces both pickers at once; there is no per-element mixing. One reason is consistency, the other is weight: loading a Shopify font and a bundled font for the same role would double the request count for no visual gain.

All four are licensed under the SIL Open Font License 1.1, which permits commercial use and self-hosting. The full texts ship with the theme at assets/PF-FONT-LICENSES.txt — keep that file in place, since the licence requires it to travel with the fonts.

The type scale

type_scale is a percentage, 100 by default. It multiplies every font size in the theme — body, headings, navigation, captions, table text — rather than only the body copy. Merchants who find the default too small can raise it to 110 and get a proportionally larger theme without a single layout change.

The 16px floor is deliberate

iOS Safari zooms the whole viewport when a focused field's text is smaller than 16px. The input size is therefore clamped at 16px even if the type scale is set lower, which keeps forms usable on a phone without disabling pinch zoom.

Heading weight

heading_weight sets the weight used by display headings: 500, 600, 700 (default) or 800. With the bundled Instrument Serif only 400 exists, so this setting has no effect while bundled fonts are on — the serif face is designed to carry weight through size rather than boldness. With a Shopify font selected, the setting works as expected.

What is intentionally tiny

Some text sits at 9–10px on purpose: the announcement ticker, eyebrow labels above headings, the SET 01/16 indices on cards, and the decorative quotation mark. These are graphic elements rather than reading matter. No content a customer needs in order to buy is set below 11px.

Changing fonts and existing content

Switching between the two font systems changes the width of every heading. Long headlines may reflow onto an extra line, and any section whose copy was written to fit exactly may now overflow. Re-read the home page after switching — that is a layout check, not a bug report.
