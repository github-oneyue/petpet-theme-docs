Reference

Section reference

PetPet Theme ships 31 sections. Each card below lists the settings that section exposes in the editor, with the value it starts with. Anything marked Liquid accepts Liquid code; everything else is a plain form field.

Adding sections

In the editor, scroll to the bottom of the sidebar and choose Add section. Sections in the home-page group appear under Add section on the home page only; template sections appear when the matching template is being edited.

How to read these tables

Setting is the key used in templates/*.json and in settings_data.json, which is what you will need when duplicating a section or asking for support. Default is the value the theme ships with — not the value in your store, which may differ once you have edited it.

Home page

Thirteen numbered sections ship in templates/index.json, in this order. Delete, duplicate or reorder them freely — the numbers are labels, not dependencies.
