Installation

Four steps to a working storefront, then five things to connect before it looks like a shop rather than a theme demo. Nothing here needs code.

Before you start

  • Shopify admin access with permission to edit themes.
  • The theme file, either from your Theme Store library or as a .zip.
  • At least one product with a price and at least one image.
  • Ten minutes, most of which is spent deciding on colours.
Keep the old theme

Shopify keeps every uploaded theme in your library, so publishing a new one never deletes the old. Do not delete the previous theme until you have clicked through the new one on a phone.

Install

From the Theme Store

  1. Buy the themeAfter checkout it is added to the theme library of the store you chose. If you bought it for a different store, use the Theme Store account page to assign it.
  2. Open your theme libraryShopify admin → Online Store → Themes. The purchased theme appears as an unpublished theme card.
  3. Customize before publishingClick Customize on the new card to open the editor. Changes here are saved to that theme only.
  4. PublishWhen you are happy, choose Publish from the theme card's action menu. The storefront switches immediately.

From a zip file

  1. UploadOnline Store → Themes → Add theme → Upload zip file, then select the archive. The zip must contain assets, config, layout, locales, sections, snippets and templates at its top level — a zip that wraps everything in a folder is rejected.
  2. Wait for processingShopify checks the theme and lists it as unpublished. A failure here almost always means a malformed .json file or a missing layout/theme.liquid.
  3. Customize and publishSame as above.

Connect the content

Menus

The header renders a Shopify navigation menu, not a list stored in the theme. Create it under Online Store → Navigation → Add menu, then point the header section at it.

WhereSettingWhat to do
HeadermenuPick your main menu. It defaults to the menu with the handle main-menu.
Footerleft_menu, center_menu, right_menuUp to three menus. Empty slots simply do not render.
Headercustomer_account_menuOptional menu shown to signed-in customers. Only relevant when the store uses classic customer accounts.

Pages the templates expect

A Shopify store always has a cart, a search page, a 404 and a password page; the theme supplies those. Two pages need creating by hand if you want them:

  • Contact — create a page, then in the page's template dropdown choose page.contact. The contact form section supplies the intro copy and the form itself.
  • About, shipping, returns — ordinary pages using the default page template. The footer menus are the usual place to link them.

Country and language selectors

The footer contains one form that submits country and language together. Each selector only renders when it has something to choose from:

  • Add countries under Settings → Markets; the selector appears once there is more than one.
  • Add languages under Settings → Languages; same rule.
  • The current choice is remembered per session, and prices update to the local market's currency.
Worth testing once

Switch the selector to a market with a different currency and open a product. Prices on the product page, the grids and the cart should all change together. If one of them does not, that market is missing a price adjustment.

Replace the demo pieces

Featured looks and Product grid ship with source set to demo. Open each section in the editor and switch the source to a collection or a hand-picked product list. See Section reference for the rest of their settings.

Go-live checklist

  • Password protection off. Online Store → Preferences. A password-protected store hides the theme from everyone but you, and it is the single most common reason a Theme Store reviewer or a customer sees the wrong page.
  • Store email set. It appears in order notifications, not in this theme, but customers will use it when the contact form fails.
  • Policies filled in. Refund, privacy and terms — checkout links to them.
  • Payment and shipping configured. The theme cannot test checkout for you.
  • Phone pass. Open the storefront on a real phone at 390px wide. Check the header, the runway and the cart drawer; those three are where narrow screens break first.
If the storefront looks unstyled

A theme that renders as plain HTML means its stylesheet did not load — usually a network or CDN hiccup, not a theme bug. Reload once. If it persists, check that assets/pawform.css appears in the theme's file list; a failed upload can drop a single asset.
