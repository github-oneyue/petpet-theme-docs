Help

Support

One person reads every message. Sending the right details in the first message is the difference between a fix today and a week of round trips.

Support is provided in English and Chinese. Replies come from a person, not a ticket robot, and are sent during GMT+8 business hours.

What to include

A message with these five things can usually be answered in one reply:

  1. Theme versionThe number in the theme editor footer, or in config/settings_schema.json as theme_version. Currently 1.0.2.
  2. Your store URLEven a password-protected one. A .myshopify.com address is enough.
  3. What you expected, and what happened"The footer country selector should appear, it does not" is actionable. "The footer is broken" is not.
  4. Steps to reproducePage, what you clicked, in what order. If it only happens on a phone, say which.
  5. A screenshot or a screen recordingFor anything visual. Include the browser's developer console if there is an error — the first line is usually the useful one.
Faster answers

The FAQ covers the five most common reports: demo pieces that cannot be bought, missing filters, missing country selectors, disappearing saved looks, and account pages that redirect to shopify.com. All five are settings or Shopify behaviour rather than theme faults.

What is covered

  • Bugs in the theme: layout faults, broken interactions, accessibility regressions, anything that differs between two installs of the same version.
  • Setup questions: which setting does what, how to get a section to look like the demo, why a Shopify feature behaves as it does.
  • Licence questions: what the bundled fonts allow, whether a use is permitted.

What is not covered

  • Custom code. Editing Liquid, adding scripts or building new sections is outside support scope. We will tell you where the relevant file is; we will not write the change for you.
  • Third-party apps. Problems that appear only after installing an app belong with that app's developer first.
  • Shopify itself. Billing, checkout configuration, domain setup and shipping rates are Shopify support's territory. The theme cannot change them.
  • Content work. Writing copy, editing photographs, choosing a colour palette.

Version support

Fixes are made against the current version and released as an update. Older versions are not patched separately; if a bug affects an older version, updating is the fix. The changelog lists what changed in each release, so you can judge whether updating is worth the re-check of your customised sections.

Before reporting a visual bug

Test once in a private window with extensions disabled. Several browser extensions inject their own CSS and markup into pages, and the resulting breakage looks exactly like a theme fault while appearing in no one else's store.

Security

If you believe you have found a security issue in the theme, email rather than opening a public issue, and include enough detail to reproduce it. Please allow reasonable time for a fix before disclosing it publicly.
