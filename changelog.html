Changelog

What changed in each release, and what to re-check after updating. Updates replace the theme wholesale, so any section you customized in the old copy stays in the old copy — see the note at the end.

1.0.3 — 15 November 2026

Copy and documentation release. No markup or layout changes, so updating is safe on a customized store.

Changed

  • Setting labels and storefront strings now use American spelling: Colors, Accent color, Center menu, canceled. Section IDs are unchanged, so saved settings carry over.

Docs

  • Every section in the theme is now documented, including the page template and the announcement marquee.
  • Support requests can be sent from a form instead of only by email.

1.0.2 — 15 November 2026

The account release. Adds the missing customer-account templates, a consistent type scale, and fixes to landmark structure.

Added

  • Seven customer account templates: login, register, account, order, addresses, activate account, reset password — plus a shared account navigation, address form and order status snippet.
  • Country and language selectors in the footer, submitted together in one form.
  • A ten-step type scale, so the font size setting now rescales the whole theme rather than only body copy.

Changed

  • Readable text no longer sits below 12px. Decorative micro-type — ticker, eyebrows, card indices — keeps its original size on purpose.
  • Text fields are clamped to a 16px minimum so iOS does not zoom the viewport on focus.
  • The account and product pages now use main landmarks, and the skip link targets them.

Fixed

  • Duplicate h1 on the product panel inside the home page.
  • Address forms did not restore a saved country on edit, only the province.

1.0.1 — 14 November 2026

Fixed

  • Each font file was requested twice: the preload used a versioned URL while the stylesheet used an unversioned one, so the cache never matched. The preload now uses the same URL the stylesheet does.
  • Bundled fonts no longer load on pages that use the Shopify font pickers.

Changed

  • Font loading moved to Shopify's font_picker by default, cutting the initial font payload from 24 files to 2.

1.0.0 — 12 November 2026

First release.

  • 31 sections including the runway look browser, the thirteen numbered home-page sections, and the template sections for product, collection, cart, blog, search and the utility pages.
  • Cart drawer, saved looks stored on the device, structured product data.
  • Four bundled typefaces under SIL OFL 1.1 with full license texts.
  • English and Simplified Chinese locales.

Updating without losing your setup

Shopify's Update action replaces the theme's files with the new version but keeps your settings_data.json and your templates, so colors, fonts and section order survive. What does not survive is any edit you made to a theme file directly, and any section whose schema changed enough that the new default no longer matches your saved values.

Duplicate before updating

Take a copy of the current theme first — Themes → … → Duplicate. It costs nothing and it is the only way back if an update surprises you. After updating, walk the home page, a product, a collection and the cart.
