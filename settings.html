Theme settings

The theme editor sidebar is organised into seven groups. This page lists every setting, the value it ships with, and what changing it actually does. Setting IDs are shown because they are what you will see in settings_data.json and in support tickets.

Where to find these

Shopify admin → Online Store → Themes → Customize. The groups below appear in the left sidebar, above the section list. Section-level settings live on their own page.

How defaults work

The values in this documentation are the ones baked into config/settings_data.json at install time. Changing a setting only affects the store you are editing; reinstalling the theme resets them. If you build a second storefront from the same theme, its settings start fresh.
